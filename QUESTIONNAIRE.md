## Implementation Notes

### Sample selection
Pick **2 samples per model** (REMI and EC-REMI), choosing ones that are neither the best nor worst — mid-range samples give a fairer impression. Suggested sample indices: `sample_05` and `sample_12`.

| Section | Clips | Sources |
|---------|-------|---------|
| Western Classical | WC-A, WC-B | `western_classical_remi/sample_05`, `western_classical_remi/sample_12` |
| Irish Folk | IF-A…IF-D | `irish_folk_remi/sample_05`, `irish_folk_remi/sample_12`, `irish_folk_ec_remi/sample_05`, `irish_folk_ec_remi/sample_12` |
| Turkish Makam | TM-A…TM-D | same pattern for `turkish_makam_remi` + `turkish_makam_ec_remi` |
| Hindustani | HI-A…HI-D | same pattern for `hindustani_remi` + `hindustani_ec_remi` |
| Carnatic | CA-A…CA-D | same pattern for `carnatic_remi` + `carnatic_ec_remi` |

**Total clips: 18** (2 WC + 4×4 traditions)

### Audio conversion
MIDIs must be converted to MP3/WAV before embedding. Use FluidSynth with a General MIDI soundfont:
```bash
# Install: brew install fluidsynth
# Download soundfont: GeneralUser GS or Yamaha XG
fluidsynth -ni soundfont.sf2 sample_05.mid -F sample_05.wav -r 44100
ffmpeg -i sample_05.wav -q:a 2 sample_05.mp3
```
Host the MP3s on Google Drive (share link) or embed directly if using a paid Form tool.

### Blind labelling
Do **not** label clips as "REMI" or "EC-REMI". Use only the letter codes (WC-A, IF-B, etc.).  
Keep a private mapping table so you can decode results later.

### Decoding results for analysis
After collecting responses, map letter codes back to REMI vs EC-REMI and compute mean scores per system per tradition. The key comparison is:

| Metric | Expected direction |
|--------|-------------------|
| Cultural Authenticity | EC-REMI > REMI for Turkish, Hindustani, Carnatic |
| Musicality | Similar or slight EC-REMI advantage |
| Coherence | Similar (both use same model architecture) |
